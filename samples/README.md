# Sample Images

All images in this folder are original photos taken by the project author.

They are used to:
- Benchmark detection speed (Spike B)
- Validate food recognition quality (Spike C)
- Demonstrate the Graveyard Shift CLI and the Witch's Pantry web UI

**No stock photos, copyrighted images, or images with unclear licenses are stored here.**
